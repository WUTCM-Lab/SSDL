# SSDL for Hyperspectral Change Detection
PyTorch implementation of "[From Pseudo-Classes to Real Changes: Spatial-Spectral Difference Learning for Mitigating Spectral Pseudo-Change in Hyperspectral Change Detection]" 

The core code has been published. The remaining code training framework can refer to https://github.com/creativeXin/AIWSEN. We thank the paper "AIWSEN: Adaptive Information Weighting and Synchronized Enhancement Network for Hyperspectral Change Detection" for its reference and contributions. Thank you for your attention!
